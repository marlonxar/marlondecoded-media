# MarlonDecoded · media

**Java, decoded daily.** Short animated explainers that turn one Java or computer-science idea into a real-world metaphor: blueprints and houses, sock drawers, train switches, theater seats. Each one runs under a minute and is made for vertical feeds.

📱 Watch on Instagram and TikTok: **@marlondecoded**

---

## What's in this repo

This repository is the public hand-off point for the MarlonDecoded channel's publishing pipeline. Each new vertical video (1080×1920 MP4) is pushed to `videos/` just long enough for the scheduler to pick it up. It is then removed and the history is squashed, so the repository stays small. The episodes themselves live on Instagram and TikTok.

| Series | Episodes | Topics |
|---|---|---|
| **Java Basics** | 01–19 | variables, int vs double, modulo, `i++` vs `++i`, immutable Strings, `==` vs `.equals()`, casting, `char` as a number, if/else order, ternary, switch arrows, while vs do-while, for, for-each, break vs continue, arrays, out-of-bounds, 2D arrays, methods |
| **Java OOP** | 01–02 | polymorphism, class vs object |

New episodes are added regularly.

## Style

- One concept per video, explained through a physical metaphor
- Flat 2D illustrated props, hand-drawn arrows and notes, Java code typed live
- Word-by-word captions, so the videos work with the sound off
- One signal color per episode, rotating across 8 palettes

## How it's made

The videos are motion-designed in HTML and GSAP and rendered with HyperFrames. The narration uses a synthetic voice (Kokoro TTS) and the sound effects are synthesized. Production is AI-assisted, and every post is labeled as AI-generated on Instagram and TikTok.
